Advanced Family Calendar

Build the Calendar Configuration field visually, test it against real (fetched, uploaded, or pasted) ICS data, and preview colors/badges using TRMNL's actual CSS — then copy the JSON into the plugin's settings. This page runs plugin/src/transform.js directly, unmodified — the same code that runs on TRMNL.

Import existing configuration (optional)

Already have a Calendar Configuration from TRMNL? Paste it here to load it into the form below instead of starting from scratch.

Hours to show (optional)

The default hour range the grid shows — always widened automatically to also cover sunrise, every actual event, and sunset, whichever push earlier/later, so nothing real ever gets hidden. Hours left outside the final range are hidden entirely rather than shown compressed.

Calendars

Add a public holiday calendar — a real Google-hosted ICS feed, no account needed. Adds it as a normal calendar above (color + flag icon pre-filled, both freely editable).

People (optional — just names + colors/badges; who a badge/color applies to is set per calendar above, under each calendar's Advanced section)

A Photo replaces the badge letter with an actual picture — but that circle is small and TRMNL's e-ink panels are grayscale/dithered, so a real photo often turns muddy at that size. A flat, high-contrast cartoon/illustrated version of the same photo reads far more clearly — imagetocartoon.com is one free way to make one before uploading it below.

Categories (optional — give events a "what kind" signal: a color bar + icon badge, matched by regex across every calendar at once)

Every event on screen gets a small color bar down its left edge. A category is what gives that bar (and the corner badge) meaning — e.g. match "birthday|verjaardag" across every calendar and show a cake icon. Icons are Google's Material Symbols, referenced by name — search below (fetched live, nothing bundled into this page) or paste a custom image URL.

Assign colors for a device (optional)

The plugin itself has no notion of "device" — it only ever uses whatever color values end up in the JSON below. This just fills in a sensible one for every calendar/person that doesn't have one pinned yet, picked for the panel you choose: TRMNL OG and TRMNL X are both grayscale-only, and even TRMNL Display Color is a 4-ink Black/White/Red/Yellow panel rather than full color, so most of the 10 named colors would otherwise collapse onto the same result there anyway. Colors already set are left alone; re-run any time after adding more calendars/people.
